# CRITICAL PERFORMANCE & COMPATIBILITY REQUIREMENTS (MOBILE-FIRST)
The application must be flawless and performant on Mobile (phones/tablets) and Desktop.
1. **No Lag/Jank Policy:** All 3D animations, transitions, and scroll effects must run at 60 FPS (Frames Per Second). Use `will-change` CSS property, debouncing/throttling, and optimized rendering loops.
2. **Responsive Design (Mobile-First):** Tailwind CSS classes must be implemented starting from the smallest breakpoint (`sm:`), ensuring touch-friendly interactions (larger tap targets, swipe gestures) on mobile and refined layouts on desktop.
3. **Optimized Assets:** For the 3D Museum and Space Station phases, ensure textures and models are compressed (e.g., using Draco compression with GLTF) to minimize loading times. Implement lazy loading for heavy components.
4. **Touch Events:** Ensure `OrbitControls` in 3D (museum and space) support touch gestures (pinch-to-zoom, rotate) natively.
5. **Smooth Scroll:** Implement a lightweight, highly performant smooth scroll library (like `Lenis`) that works seamlessly on both touch devices and trackpads/mouse wheels.
