# Detailed Project Phases (The User Journey)

The application consists of 6 sequential phases/chapters. You will build them perfectly as described:

## Chapter 1: The Landing Gate (Password Protection)
- **Route:** `/`
- **Visuals:** A full-screen cinematic animated background (fading stars or a gentle ambient glow using Framer Motion). Centered on the screen is a glowing text: "Happy Birthday [Name]".
- **Functionality:** Below the text is an elegant, glassmorphic PIN/Password input field.
- **Logic:** The input verifies against a specific `secretDate` or `pin` from `data.ts`.
  - On success: Trigger a grand unlock animation (e.g., screen splits open or fades to white), then `router.push('/museum')`.
  - On fail: Trigger a smooth horizontal shake animation on the input field and display a subtle red error text.

## Chapter 2: The 3D Memory Museum
- **Route:** `/museum`
- **Visuals & Tech:** Use React Three Fiber. Render a 3D gallery room or an ethereal dark space. The user can look around using `OrbitControls` (with limited pan/zoom).
- **Elements:** Render 4 to 6 floating 3D frames (using a BoxGeometry or PlaneGeometry with textures). Map the images from `data.ts`.
- **Interaction:** When the user clicks a 3D frame, the camera smoothly zooms in on it, and an HTML modal (using `@react-three/drei` Html component or a standard React overlay) fades in. The modal displays the high-res image, a title, and a voice note audio player (referencing `data.ts`).
- **Progression:** A glowing "Next Chapter" button appears after they interact with at least one frame, leading to `/story`.

## Chapter 3: The Interactive 2D Story
- **Route:** `/story`
- **Visuals:** A retro, nostalgic 2D interface. It should feel like a cozy "Visual Novel" or a stylized text adventure.
- **Functionality:** Display text sequentially (typewriter effect). It narrates the story of how the couple met, fetching chapters from `data.ts`.
- **Interaction:** At the end of each narrative block, present 2 choices (e.g., "What was I thinking?" vs "Where did we go next?"). Both choices are correct but reveal different cute anecdotes.
- **Progression:** Completing the short story reveals the portal to the Core Hub (`/hub`).

## Chapter 4: The Core Hub (Media, Map & Analytics)
- **Route:** `/hub`
- **Architecture:** A complex dashboard with a Sidebar navigation (Glassmorphism) containing 3 tabs.

### Tab 1: Personalized Streaming Platform (Netflix Clone)
- **Visuals:** A Hero section with a massive cover image, title, and a "Play" button. Below it, create 3 horizontal scrolling rows (e.g., "Season 1: The Start", "Season 2: Adventures", "Soundtracks").
- **Interaction:** Hovering over a card scales it up slightly. Clicking opens a customized video/audio player modal.

### Tab 2: The Celestial & Real Map
- **Visuals:** Integrate a map component (can use a stylized simple SVG map or Leaflet if instructed later).
- **Interaction:** Mark 3 critical locations (coordinates from `data.ts`). When a pin is clicked, the background transitions to a "Night Sky / Star Map" mode showing a generated constellation pattern overlay, alongside a romantic message about that location.

### Tab 3: Love Data Analytics
- **Visuals:** A highly professional yet romantic dashboard using `recharts`.
- **Components:**
  1. Top metric cards: "Days Together", "Messages Sent", "Loudest Laughs".
  2. Line Chart: "Chat Frequency Over the Years" (smooth curve, gradient fill).
  3. Bar Chart: "Most Used Words" (e.g., 'Love', 'Miss you'). Ensure tooltips are styled elegantly.

## Chapter 5: Generative Art & Soundwave
- **Route:** `/art`
- **Component 1 (The Tree):** Use HTML5 Canvas to procedurally draw a tree that grows its branches on page load (Generative Art). Make the leaves bloom. Clicking specific leaves reveals hidden messages.
- **Component 2 (The Soundwave):** Display a visual audio waveform (SVG or Canvas). When the user clicks play, an audio track (from `data.ts`) plays, and a subtle glowing animation travels across the waveform synced with time.
- **Progression:** A button at the bottom: "Proceed to the Final Gift".

## Chapter 6: Digital Constellation Time Capsule (The Finale)
- **Route:** `/capsule`
- **Visuals:** A deep space 3D or 2.5D environment using Framer Motion.
- **Elements:** 3 distinct "Planets" or glowing orbs.
  - **Planet 1 (The Present):** Glowing brightly. When clicked, it expands to fill the screen and displays a final heartfelt video/message and the instructions/code for the REAL physical birthday gift.
  - **Planet 2 & 3 (The Future):** Grayed out or locked with a translucent padlock icon. Hovering shows a tooltip with a countdown timer (e.g., "Unlocks on your next birthday").
- **Audio:** A subtle, emotional background track autoplays (if browser permits) upon entering this final page.
