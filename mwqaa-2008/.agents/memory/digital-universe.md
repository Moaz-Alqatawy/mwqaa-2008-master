name: Digital universe experience
description: The birthday site's space finale favors a lightweight CSS simulation for broad device performance.
---

The digital-universe finale intentionally uses CSS-rendered stars, a layered real-place portal, moving water/light/fireflies, glass cards, and pointer parallax instead of a WebGL/Three.js scene.

**Why:** The birthday site is a frontend-only gift that should open smoothly on phones and avoid adding a heavy 3D runtime for a decorative interaction.

**How to apply:** Keep future changes to this experience lightweight and emotionally focused; add deeper interaction through CSS layers and small React state changes before considering a heavy 3D runtime.
